## 3. Варианты исправления (решение владельца, см. вопрос в чате)

A. **Взять карты эталона как данные.** Файлы `resources/maps/*` по `LICENSE-ASSETS` лицензированы CC BY-SA 4.0:
   нужна атрибуция «OpenFront» и совместное использование по той же лицензии (производные карты тоже BY-SA). Формат
   `map.bin` документирован в конвейере эталона. Пиксельно совпадаем с эталоном сразу.

B. **Свой конвертер по документированным правилам** (пункт M3–M5) с нашими исходными изображениями. Лицензия на
   исходные PNG (`map-generator/assets`) тоже требует проверки. Совпадение с эталоном проверяем по байтам `map.bin`
   для одного и того же входа.

Предварительно рекомендую A для точного совпадения, но это юридическое решение, его принимаете вы.

## 3a. Решение владельца (2026-10-16): вариант B

Выбран вариант B (свой конвертер по правилам эталона). Ограничение: побайтное совпадение с эталоном требует того же
исходного изображения (синий канал). Наш `World.png` закодирован палитрой, поэтому без исходника эталона точного
совпадения не будет. Исходник `map-generator/assets/maps/*/image.png` в `LICENSE-ASSETS` явно не описан (BY-SA
указан для `resources/`). Нужно подтверждение: можно ли использовать исходники эталона и производные карты по BY-SA с
атрибуцией «OpenFront». Пока статус M1–M5: не выполнено.

## 5. Пилот собственного генератора (2026-10-16, статус: НЕ принят)

Скрипты: `client/scripts/maps/generate-pilot-map.mjs` (генератор, сид → PNG+JSON) и
`client/scripts/maps/measure-map.mjs` (замер теми же метриками, что эталон). Выход — `client/build/pilot/` (не в git),
`resources/maps/World|Europe` не менялись.

Параметры по умолчанию: world 2000×1000, сид 1, суша 32.6%, рельеф 34/38/28 от суши, порог островов 20 клеток,
фрактальный шум 5 октав (256…16 и 8 клеток), пиксельный шум у берега ±0.02.

Замер на сиде 1 (цель эталона `world`):
| Метрика | Пилот | Цель | Допуск | Итог |
|---|---|---|---|---|
| Суша, % | 32.58 | 32.6 | ±1 п.п. | OK |
| Равнина / холм / гора, % суши | 34 / 38 / 28 | 34 / 38 / 28 | ±2 п.п. | OK |
| Берег, % суши | 3.64 | 3.9 | ±1 п.п. | OK |
| Тела суши ≥100 клеток | 57 | 53 | ±30% | OK |
| Крупнейшее тело, % суши | 33.97 | 34.7 | инфо | близко |

Детерминизм: два запуска с одним сидом дают одинаковый SHA-256 (`28686b2d…`). Время генерации ~2 с.

**Что не так (причина, по которой пилот не принимаем):**
1. Устойчивость по сидам. Параметры подобраны на сиде 1. На сидах 2 и 3 тел ≥100 стало 19 и 29, крупнейшее тело — 31% и 62%.
   Значит, совпадение со статистикой случайно для одного сида, а не свойство алгоритма.
2. Визуально (сверка `preview-Pilot.png` против `World.png`): архипелаг из округлых пятен; нет материков, горных цепей
   и полярного пояса; горы выглядят концентрическими кольцами (рельеф задан квантилями высоты, а не геологией).
   По цифрам карта проходит, по виду — нет.
3. Слой «Полный» (текстуры, реки, биомы) не реализован: сделан только базовый цветовой шум ±3.
4. Палитра PNG не хранит флаг «океан» и величину воды, поэтому метрики `ocean%` и `water_mag` не замерены.

Следующий шаг (до масштабирования): добавить геологическую основу (несколько крупных плит с направлением и горными поясами
вдоль границ), проверить на 5+ сидах (допуски по всем сидам, не по одному), затем визуальная сверка с World.
