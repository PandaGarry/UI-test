Особенности, которые легко потерять при переписывании:
- Слайдер: перетаскивание через `registerClickListener`/`registerDragListener`, плюс скрытый `<input type=range>` для клавиатуры и доступности.
- Подпись слайдера переворачивается, когда значение < 0.2 (чтобы не перекрывать полосу).
- Контейнер HUD по умолчанию перетаскивается: нажатие и удержание по пустому месту двигает карту.
- Адаптивность: нижний селектор на телефоне (`min-width: min(500px, 90%)`, исправлено в `1614cb9`), safe-area, touch-цели 44px.

## Порядок работ

4. Визуальная полировка и тесты на отдельные функции (formatDensity, кривая слайдера).

## Решения

- Пустой список лидеров скрыт (`:empty`), до появления территории пустой полоски нет.
- Граница «телефон / широкий экран»: `(min-width: 768px) and (min-height: 512px)`. Телефон в альбомной ориентации (844×390) остаётся с переключателем.

- Перетаскивание карты через HUD (удержание 1 с) сохраняем.
- Лидерборд на телефоне: в углу одна строка «место · доля игрока», полный список открывается по нажатию и закрывается тем же способом. На десктопе топ-5 и строка игрока видны всегда. Постоянный список из пяти строк на телефоне отвлекает и закрывает карту.
- Поведение Terron по лидерборду не проверено; решение основано на удобстве игрока на маленьком экране.
