# Визуальные слои карты — состояние и решения (2026-10-16)

Этот документ — рабочий журнал слоёв отрисовки. Геймплейные данные описаны в
`MAP-ARCHITECTURE-2026-10-16.md` (F — фундамент; поправка про реки там же). Здесь — только вид.

## Правило

Визуальные слои не меняют геймплей. Фундамент F не читает ни один визуальный слой.
Всё, что игрок может выключить, включается через настройку во вкладке «Интерфейс».

## Текстуры T

- Основа: `scripts/textures/periodic-base.py` — шум FFT на торе, края совпадают математически.
- Детали: `scripts/textures/compose-details.py` — ИИ-мазки (`resources/textures/src/`), только яркостная
  составляющая, зеркальный период 512 px. Отношение шва к внутренним перепадам 0.82–0.92.
- Цвета: из палитры темы (равнина `rgb(190,220,138)`, холмы `rgb(220,203,158)`, горы `rgb(230,230,230)`,
  вода `rgb(71,133,181)`). Детали цвет не сдвигают.
- Исходники ИИ-текстур (`src/`, 1024 px) не в Git: крупные. Итоговые плитки (512 px) в Git.

## Тонирование владельца территории (решение)

Выбрано владельцем: текстура остаётся видимой, цвет владельца мягко тонирует плитку.

Механика: вместо непрозрачной заливки территория умножает яркость текстуры на цвет владельца:
`итог = текстура_лума × цвет_владельца` (режим multiply), границы и внутренняя линия — как сейчас.

Что потребуется:
1. Загрузить плитки T в GPU (атлас 512×2048, по одной на класс).
2. В шейдере карты выбирать класс по типу клетки (палитра уже содержит тип → цвет; добавить канал класса).
3. В шейдере территории: режим multiply вместо альфа-смешивания, с сохранением границ.
4. Проверка в браузере на обеих картах и при смене владельца.

Статус: решение принято, реализация следующим шагом. Текущая территория (альфа 0.5, светлота 0.75)
остаётся рабочей до реализации.

## Что проверено

- Фундамент с реками: 0 клеток рек на суше (World, Europe); тесты 90/90.
- Песок и глубина: в браузере включение/выключение меняет вид только у берега; ошибок в консоли 0.
- Текстуры: стыки 2×2 без видимых швов (число и глаз).

## Что не проверено

- Барьер реки в игре (захват через реку недоступен, лодка проходит): подтверждено данными
  (тип «Water», `conquerable=false`, `navigable=true`), в браузере — нет.
- Вид текстур в игре, тонирование владельца, качество на слабых устройствах — нет.

## Следующие шаги (по порядку)

1. Подключить T к рендеру карты (атлас, класс по типу клетки), выключено = прежний вид.
2. Тонирование владельца (multiply) в шейдере территории.
3. Уровни качества T (выкл / низкое / высокое) и переключатель в настройках.
4. Восстановить браузерные инструменты и проверить: вид, владельца, барьер реки.
5. Затем — третий регион и бой.

## Подключение T к рендеру (2026-10-16)

- Атлас `client/resources/textures/atlas.png` (512×2048; полосы: plains, hills, mountains, water), собирается `client/scripts/textures/build-atlas.py`.
- Шейдер `MapRenderingShader.frag` берёт класс по типу клетки (`tile_class`), делит выборку на среднее класса (`class_mean`), масштаб `tile_cells` = 96.
- Настройка `map-textures` (по умолчанию включена, `interfaceGeneral`) выключает слой полностью: вид — плоская палитра. Геймплей не меняется.
- Если атлас не загрузился, слой выключается сам (предупреждение в консоли), карта остаётся.
- Проверка в браузере (chromium, `tex.mjs`): ошибок консоли нет при on/off; снимки on/off различаются.
- Сервер: `scripts/serve.js` раздаёт `/resources/*` из `client/resources` (раньше отдавал HTML-заглушку для шрифта и атласа в `npm start`).
- Формат сохранения настройки в localStorage: `значение:версия` (например, `false:0`).

## Территория в режиме multiply (2026-10-16)

- Решение `tint`: при включённых текстурах (`MapRenderer.texturesActive()`) территория пишет множитель `mix(1, цвет владельца, альфа)` и композитится как `DST_COLOR, ZERO`. Текстура под территорией остаётся видимой.
- Кэш территории очищается в белый (нейтральный множитель) вместо прозрачного; смена режима вызывает очистку и перерисовку (`clearPending`).
- Выключено: прежняя альфа-смесь, прежний вид.
- Проверка: снимки `terr-off2.png` (плоско) и `terr-on2.png` (текстура) при `map-textures` `false:0`/`true:0`; ошибок консоли нет; `npm test` 90/90.
- Оценка силы тонирования на глаз слабая: владельцы видны значками, цвет почти не читается. Требуется отдельная проверка на крупном масштабе.

## Уровни качества T (2026-10-16)

- Три уровня через две настройки: `map-textures` (выкл / атлас) и `map-texture-tint` (тонирование территории). Выкл = плоская палитра; низкое = атлас без тонирования; высокое = атлас и тонирование.
- Сила тонирования: `TINT_STRENGTH = 1.5` к альфе территории (0.5 → 0.75, решение «сильная»).
- Проверка: `terr-high.png` (true:0 / true:0), консоль без ошибок. На масштабе карты владельцы почти не читаются по цвету — требуется проверка крупным планом (открыто).

## Тонирование территории: темнее и насыщеннее (2026-10-16)

- Обратная связь владельца: тонировка слишком светлая, границы чужой территории неразличимы. Причина: цвета темы пастельные (светлота 0.75), множитель из них почти не темнит.
- Теперь в режиме multiply (текстуры и тонирование включены): заливка — базовый цвет игрока со светлотой 0.55, сила 0.8; граница — светлотой 0.35, сила 1. Обычный режим (тонирование выключено) не менялся.
- Проверка: `zoom-tint3.png` (World, 70 с после старта): владельцы видны, границы читаются лучше; цвета остаются приглушёнными. Требуется проверка на телефоне владельца (Europe, Replit) и сравнение с эталоном по границам.
