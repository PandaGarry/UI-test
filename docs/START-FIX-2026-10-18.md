# Исправление старта игры с государствами (18.10.2026)

## Симптом
Игра со государствами (World, Europe, Africa) не стартовала: после «Старт игры» игра возвращалась в меню без ошибки на экране.

## Причина
- `PlayerManager.init` ставил государства на их стартовые клетки через `spawnManager.placeAt`.
- `placeAt` вызывает захват территории (`territoryManager.conquer` → `addTile`).
- Клиентский обработчик `gameInitRegistry` (сброс `PlayerNameRenderingManager.reset`) срабатывал позже.
- `PlayerNameRenderingManager.addTile` падал: `TypeError: Cannot set properties of undefined (setting '595015')`.
- `tryStartGame` перехватывал ошибку и отправлял её в `gameLoadFailRegistry`, поэтому игра тихо возвращалась в меню.
- Регрессия внесена при переработке государств. Тесты её не ловили, потому что не рисуют карту.

## Исправление
- Создание объектов `NationPlayer` осталось в `PlayerManager.init`.
- Размещение вынесено в новый метод `PlayerManager.placeNations()`.
- `startGame` (`packages/core/src/game/Game.ts`) вызывает его сразу после `gameInitRegistry.broadcast()` и до `randomizeSpawnPoints()`.
- `placeAt` не использует генератор случайных чисел, поэтому детерминизм не меняется.
- Если стартовая клетка не суша, выбрасывается ошибка с именем государства (манифест неверен).

## Проверки
- `tsc` (core и client) без ошибок; тесты 161/161; `determinism-check` без изменений (`STATE_HASH=f27a333a`).
- World, 400 ботов, 1500 тиков, seed 1: `alive 169/169, tiles 280002, largest 18963` — совпадает с результатом до переноса.
- Браузер (Chrome 131, headless): старт World с 400 ботами и государствами доходит до HUD, первый кадр игры 1747 мс.
- Тап по карте после окончания фазы выбора спавна открывает радиальное меню (4 элемента), подсказка при наведении на «Информация» выводится по-русски. Ошибка `this.action is not a function` в этом прогоне не воспроизвелась.

## Вёрстка лобби (сложность государств)
- Причина, почему класс `is-wide` не давал нужной ширины: в медиазапросе от 720 px `.lobby-card.is-wide { grid-column: auto }` сбрасывал растяжение, а сетка стала четырёхколоночной.
- Исправление: карточка сложности `.lobby-card.lobby-states-difficulty` занимает три колонки рядом с карточкой «Государства»; на узком экране — всю строку.
- Все четыре уровня (Легко / Средне / Сложно / Невозможно) видны без наложения.

## Открыто
- Текст экрана загрузки и часть интерфейса в браузере по умолчанию на английском («Loading map…», «Start game»). Русский интерфейс нужно включить настройкой языка; проверка переключения ещё не выполнена.
- В консоли есть предупреждение WebGL «Two textures of different types use the same sampler location». Ошибка не останавливает игру, причину ещё не установили.
