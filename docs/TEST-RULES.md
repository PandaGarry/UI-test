# Правила проверки (обязательны для каждого изменения)

1. **Сначала тест, потом пуш.** Ни одно изменение не пушится без прохождения теста на текущей сборке.
2. **Проверка по числам, не на глаз.** Тесты сравнивают кадры по пикселям и печатают PASS/FAIL. Скриншот смотрю отдельно и записываю, что на нём видно.
3. **Тест должен уметь падать.** Если проверка не может провалиться (например, пустой выбор спавна), это дефект теста. Такой тест правится до того, как ему верят.
4. **Каждое изменение получает номер проверки** в `chrtest/cam.mjs` (C1…Cn) и описание в `docs/STATUS.md`.
5. **Отчёт сохраняется** в `/home/user/chrtest/reports/*.json` с коммитом сборки.
6. **После каждой проверки спрашиваю пользователя**: «Так правильно? Закрепляем?» Статус меняется на «одобрено» только после ответа пользователя.
7. **Не пушить без одобрения, если правка меняет поведение, уже одобренное пользователем.** Исправления ошибок, найденных тестом, можно пушить сразу, с записью в статус.

## Текущий набор: `chrtest/cam.mjs` (камера)
- C1 первый выбор валидного спавна меняет карту (>25% пикселей).
- C2 второй выбор спавна не приближает ещё раз (<8%).
- C6 зум сохраняется при старте игры (вид в игре = вид после выбора, <8%).
- C3 тап в игре не двигает камеру (<3% вне кольца).
- C4 кольцо открывается в точке касания (±20 px, либо прижато к краю).
- C5 нет ошибок страницы.

Ограничение: C2 пройдёт и если выбор отклонён. Нужна отдельная проверка принятия спавна (TODO).

## Стресс-тест меню (chrtest/stress.mjs)
- 400 ботов (лобби), сетка тапов по карте + одна точка повторно.
- Считает: открылось ли кольцо; включена ли атака; изменился ли список атак; тихие отказы (атака включена, клик без результата).
- Критерий: тихих отказов 0, меню открывается на всех тапах по карте.
