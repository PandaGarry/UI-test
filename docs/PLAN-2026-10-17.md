## Правила работы

- Перед работой: `AGENTS.md`, bootstrap. Перед коммитом: `npm test`, `npm run build-prod` (код выхода без пайпа), проверка в браузере.
- Каждый шаг: код → тесты → браузер (World/Europe) → документ в `docs/` → коммит → push.
- Фундамент (суша, вода, территории, спавн) не зависит от графики. Визуальные слои не меняют геймплей.
