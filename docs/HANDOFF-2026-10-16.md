## 3. Установка окружения

Нужно:
- Node.js 20 или новее (CI использует 20, локально работали на 22).
- npm (идёт с Node).
- Bun **1.2.9** (сервер и сквозной тест раннера). Установка: `npm i -g bun@1.2.9` или `npm i bun@1.2.9 --prefix ~/tools` и затем `PATH=~/tools/node_modules/.bin:$PATH`.
- Python 3 (скрипты анализа карт в `scripts/map-analysis/`).
- Chromium для браузерных проверок. В песочнице его ставили так: в отдельной папке (не в репозитории) `npm i @sparticuz/chromium puppeteer-core`, затем путь берётся из `chromium.executablePath()`. Для запуска нужны библиотеки: `LD_LIBRARY_PATH=/tmp/al2023/lib:/tmp`. Переменные: `CHROME_PATH=<путь>`.

Установка репозитория:
```
git fetch origin && git checkout arena/0330549f-ui-test && git pull --ff-only
cd client && npm ci && npm run gen-maps        # карты для клиента и тестов
cd ../server && bun install                    # после правок packages/core повторять
```
Важно: `bun install` в `server/` копирует `packages/core`, а не создаёт ссылку. После любых правок в `packages/core` нужно повторить `bun install` в `server/`. Клиент (npm) использует симлинк и видит правки сразу.

## 5. Как работать корректно

Правила проекта (из переписки с пользователем и `docs/PARITY.md`):
- Эталон — Terron (`github.com/openfrontio/OpenFrontIO`, AGPL). Его можно читать и сверяться с ним. Код не копируем. Расхождения записываем в спецификацию с датой и способом получения. Ассеты `resources/` эталона — CC BY-SA 4.0, с атрибуцией.
- Тесты, а не догадки. Причину ищем зондами или тестами, устраняем причину, а не обходим. Зонды и временные логи удаляем до коммита, проверяем `grep -rn TEMP-DEBUG`.
- Замеры радиального меню и тапов — только на production-сборке (dev с зондами загрязняет результаты). Dev-проверки выполнять на чистом dev-сервере после перезапуска.
- Каждый тест или нововведение — вопрос пользователю с вариантами (`ask_user`). Не решать за него то, что он не делегировал: например, мерж в `main`, порог карт, структура репозитория.
- UI откладываем. Текущий приоритет: карта → бой (радиальное меню, атака, тапы/клики, оптимизация) → UI/UX до уровня эталона. Нижняя панель утверждена (`IMG_5799`), не менять без сверки.
- Коммиты: осмысленное сообщение, дата в конце, тесты перед коммитом. Пуш только `git push origin HEAD:arena/0330549f-ui-test` (или `git push origin arena/0330549f-ui-test`, если на ветке).
- Не коммитить артефакты: `out/`, `node_modules/`, `build/`, карты, сгенерированные в `resources/maps` только если это уже принятая практика в репозитории (см. `client/scripts/generate-local-maps.ts`).
- Не удалять `docs/calibration-*.txt`: на них ссылается `docs/PARITY.md`.
- `scripts/arch/check-boundaries.cjs` — правило папок. Не отключать, не расширять исключения без решения.
- Решение о структуре репозитория (npm workspaces, мерж в main, переписывание истории) — только по согласованию с пользователем.
