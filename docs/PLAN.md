# Детальный план развития Frontline

Стратегия, уникальность, стек и бюджеты производительности — в
[VISION.md](VISION.md). Здесь — пошаговый план работ с критериями приёмки.
Главное правило: **мы не догоняем Terron по списку фич — мы делаем свой
вариант жанра**, исправляя ошибки предшественников.

## Незыблемые принципы

1. **Стабильность важнее фич.** Этап не готов, пока: тесты зелёны, сборка
   чистая, perf-бюджеты (VISION.md) не нарушены.
2. **Баланс — цифрами.** Все игровые числа — в
   `client/src/game/BalanceConfig.ts` (позже `packages/core`). Каждая правка
   баланса — отдельный коммит + bot-vs-bot проверка.
3. **Детерминизм.** Симуляция зависит только от сида и действий; случайность
   только через сид-PRNG ядра.
4. **Локализация RU+EN.** Ни одной строки в UI без ключа словаря.
5. **Лицензионная чистота.** Код и ассеты Terron/OpenFront не копируем —
   только идеи механик.
