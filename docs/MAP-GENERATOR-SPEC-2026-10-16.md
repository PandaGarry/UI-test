# Собственный генератор карт: спецификация (этап 3), 2026-10-16

Цель: свои карты, статистически совпадающие с эталоном по рельефу, береговой линии, островам и
распределению суши. Пиксельное совпадение не цель (чужие карты не используем: лицензия).
Код генератора пишем сами, по этой спецификации. Эталонный конвейер и его файлы только читаем для статистики.

## 2. Алгоритм (детерминированный, сид → карта)

1. **Генератор случайных чисел:** целочисленный PRNG (например, mulberry32) от сида карты. Без `Math.random`.
2. **Шум без тригонометрии:** значение-шум по целочисленному хешу узлов сетки, сглаживание полиномом
   `t·t·(3−2t)`, октавы суммируются. Никаких `sin/cos/exp/log/pow` (совпадает с требованием к детерминизму R4).
3. **Маска суши:** поле высот = фрактальный шум + маска «континентов» (K центров, радиус по закону). Порог
   выбирается квантилем так, чтобы суша была точно равна целевой доле (параметр карты).
4. **Удаление мелких тел:** тела суши меньше `minIsland` (по умолчанию 20 клеток, порог подбирается по статистике
   эталона, в эталоне есть тела < 100 клеток) заменяются водой; тела меньше порога и связанные с крупным телом
   присоединяются к ближайшему соседу по приоритету большинства соседей.
5. **Рельеф:** величина суши 0–31 = квантиль высоты внутри суши. Классы: равнина < 10, холм 10–19, гора ≥ 20.
   Доли классов по квантилям = целевые доли из таблицы (параметр карты).
6. **Вода:** величина = min(31, ceil(расстояние до суши / 2)) (BFS). Флаг «океан» = вода, связанная с краем карты.
   Флаг «берег» на суше = есть сосед-вода. Ожидаемо 1–4% суши.
7. **Совместимость с нашим конвейером:** результат записываем как `resources/maps/<Name>.png` (палитра) и
   `<Name>.json` (типы: Water, Plains, Hills, Mountains, с conquerable/navigable/expansionCost), далее работает
   существующий `npm run gen-maps`. Позже (этап 4) — прямой бинарный формат с битами, как у эталона.

## 3. Проверка (обязательная)
- Замер нашей карты тем же скриптом, что эталон. Допуски: суша ±1 п.п., классы ±2 п.п. от цели, берег ±1 п.п.,
  число тел ≥100 в пределах ±30%.
- Тест детерминизма: два запуска с одним сидом дают одинаковый файл (побайтно).
- Визуальная сверка скриншотов: береговая линия, острова, горы.

## 4. Порядок работ
1. Пилот: одна карта (world-размер, цели из таблицы), замер, визуальная сверка. Не переходим дальше без вашего
   подтверждения.
2. Остальные карты по таблице целей.
3. Миниатюры 4x/16x (для обзора и производительности).
4. Нации: координаты на суше, разнесённые по расстоянию (позже, отдельная спецификация).
