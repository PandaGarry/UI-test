# Проект «ЯВЬ» — индекс документации

> Рабочее кодовое имя проекта: **ЯВЬ** (`JAV` в коде, файлы, пакеты).
> Жанр: мобильная MMO-4X стратегия (city builder + мировая карта + альянсы + сезоны).
> Референсы жанра (только механики, без IP): Game of Thrones: Conquest, Viking Rise, Rise of Castles, Rise of Kingdoms, Evony.
> Сеттинг: **оригинальный**, тёмное славянское фэнтези. Без использования чужих вселенных.

---

## 1. Зачем этот пакет документов

Мы договорились, что первый шаг — **план**, по которому дальше двигаемся. Этот пакет — не «презентация», а рабочий инструмент:

- по нему **пишется код** (архитектура, протокол, схема данных описаны до строчки кода);
- по нему **балансируется игра** (в документе дизайна стоят конкретные числа-стартовые значения, а не «настроим потом»);
- по нему **пишется контент** (сценарий, тексты, имена, арки сезонов — готовы к вставке в конфиги);
- по нему **понятно, что тестировать** на каждом этапе.

## 3. Принятые решения (журнал ADR)

Формат: `ADR-n · дата · решение · причина · что отвергли`.

| ID | Решение | Причина | Отвергли |
|---|---|---|---|
| ADR-1 | **Сеттинг оригинальный — славянское тёмное фэнтези («Явь vs Навь»)** | «Игра престолов» и др. — чужой IP: юридический риск и требование лицензии. Славянская мифология — общественное достояние, при этом в мобильных SLG почти не занята (ниша) | Прямой клон GoT/RoK по именам и арту |
| ADR-2 | **Клиент сначала веб (PWA), потом упаковка в Android через Capacitor** | Единственный вариант, при котором игру можно показать/протестировать прямо в этой среде и в Replit бесплатно, без Unity-редактора и без VDS. Один код — браузер + APK | Unity, Cocos, Godot на старте (дороже итерации, не проверяемо здесь) |
| ADR-3 | **Сервер — свой на TypeScript (Node 22), без форка чужого движка** | В окружении нет Go/Docker; Node 22 + npm workspaces работают и здесь, и в Replit. Ключевая причина: полностью детерминированное ядро, idempotent-команды, журнал событий — то, что в готовых форках переписывать дольше, чем писать | Форк `llr104/slgserver` (Go, не запускается здесь; UPDATE в БД на каждое действие), `Nakama` (всё равно писать свою логику, но в чужой модели), `SpacetimeDB` (интересно, но риск подписок на карте 1М тайлов) |
| ADR-4 | **Авторитарный сервер + асинхронная «приказная» симуляция, мировой тик 1 Гц** | В жанре нет realtime-синхронизации: всё решается таймерами и отложенными задачами. Это и есть причина, по которой 1000+ игроков на мир — обычная инженерная задача, а не чудо | Tick 20–60 Гц с предсказанием клиента (не нужен жанру, дорого) |
| ADR-5 | **Мир = один процесс (single-writer). Масштаб — шардингом по королевствам** | Отсутствие гонок внутри мира; масштабирование линейное и дешёвое. Позже — кластеры миров с общей БД | Кластер с распределённым состоянием мира на старте |
| ADR-6 | **Контент — данными, не кодом** (`packages/content`, JSON/TS) | Баланс правится без пересборки; правки баланса не ломают билды; можно дать доступ дизайнеру/тебе | Хардкод чисел в логике |
| ADR-7 | **Один «мир-демо» с ИИ-наполнителями («Мороки») уже на этапе M2** | Пустой мир неиграбелен и нечестен к тестам: альянсовые войны требуют плотности игроков. Мороки дают живость при любом онлайне и одновременно служат нагрузочными ботами | «Подождём настоящих игроков» |
| ADR-8 | **Мобильный дизайн-таргет: 60 FPS на 3-летнем среднем Android, RAM < 400 МБ, трафик < 3 МБ/час геймплея** | Это прямые требования жанра и главный источник отвала на слабых устройствах | «Сделаем красиво, потом оптимизируем» |

## 5. Термины-сокращения, которые используются в документах

| Термин | Значение |
|---|---|
| **Мир / королевство (kingdom)** | Один игровой мир со своей картой, своим процессом на сервере. Игроки внутри мира между собой воюют, между мирами — нет |
| **Мороки** | ИИ-игроки, населяющие мир (наш аналог «ботов-наполнителей») |
| **Прилив Нави** | Сезонный сброс мира: карта перекраивается, прогресс сезонных механик обнуляется, постоянные вложения (герои, звания) остаются |
| **Оберег (Ward)** | Игровая «магия» и главная метафора защиты: нити света, которые игроки плетут между сторожевыми столбами |
| **Род (Kin)** | Альянс: до 100 игроков, общая территория, общие нити, ралли |
| **Острог (Hold)** | Город игрока |
| **PPC / CCU / ARPDAU** | метрики: платящая конверсия, одновременный онлайн, средний доход с активного игрока в день |
| **DoD** | Definition of Done — критерий «этап закрыт» |
