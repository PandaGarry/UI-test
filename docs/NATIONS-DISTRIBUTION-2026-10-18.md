# Распределение государств и ботов: как в эталоне и что нужно у нас

Дата: 2026-10-18. Эталон: `420f27a` (`/home/user/reference/OpenFrontIO`). Документ фиксирует механизм, а не копирует данные.

## 1. Два разных понятия в эталоне
- **Государства (nations)**: `PlayerType.Nation`. Берутся из манифеста карты, у каждого есть имя, стартовая клетка (координаты) и флаг. Отдельная логика поведения (см. `docs/NATIONS-PLAN-2026-10-18.md`).
- **Боты (tribes)**: `PlayerType.Bot`, число задаётся `config.bots`. Спавнятся случайно на суше (`execution/TribeSpawner.ts`), клетки государств им передаются как запретные (`nationTiles`), чтобы боты не ставились поверх государств.

## 2. Откуда список государств
- Манифест карты: `map-generator/assets/maps/<карта>/info.json`, поле `nations`: `{name, coordinates:[x,y], flag}`.
- Примеры в эталоне: мир (`world`) 72 государства, Европа (`europe`) 52, Африка (`africa`) 44. Поле `additionalNations` есть в схеме, но в этих трёх картах пустое.
- Размеры изображений карт: мир 2000×1000 (у нас `World.png` тоже 2000×1000, координаты переносимы напрямую); Европа 2905×1674 (у нас 2904×1672, расхождение 1–2 пикселя); Африка 1950×2032 (у нас 1440×1480, нужен пересчёт координат, это другая вырезка).

## 3. Правила распределения (`packages/engine/src/game/NationCreation.ts`)
- `config.nations`:
  - `"disabled"` — государств нет;
  - число — ровно столько; если больше манифеста, сначала добираются `additionalNations`, затем процедурные имена;
  - `"default"` — все государства манифеста, кроме:
    - публичного режима «люди против государств»: число равно числу людей;
    - компактных карт: 25 % (минимум одно), `getCompactMapNationCount`.
- Выбор и порядок: `random.shuffleArray(manifestNations)`, затем срез нужного числа. Генератор детерминированный (`PseudoRandom`).
- Ботов по умолчанию 400 (`bots: 400` в лобби, `SinglePlayerModal.ts`, `MapPlaylist.ts`); для компактных карт по умолчанию 100 (`LobbySettingsSummary.ts`). Схема ограничивает `bots` максимумом 400 (`engine-api/src/Schemas.ts`).
- Имена ботов: `TribeNames.ts`, темы карты (`themes` в `Maps.gen.ts`), у нас уже реализовано по образцу.

## 4. Что у нас сейчас
- Карты: `client/resources/maps/{World,Europe,Africa}.json` (только таблица тайлов). Манифестов государств нет.
- `startGame(map, mode, seed, humans, ...)` не принимает список государств. Игрок-«государство» отсутствует.
- Количество ботов в игре: не 400, а значение из лобби/харнесса (по умолчанию в `perf-sim` 30). Нужно выровнять по 400 и проверить бюджет тика (`docs/VISION.md`).
- Имена ботов: `client/src/app/BotNameGenerator.ts` (страны и племена).

## 5. Предлагаемый порядок (после решения по данным)
1. Манифест для мира (и Европы, Африки): список государств, координаты, без цифровых суффиксов.
2. Загрузка манифеста рядом с картой; `startGame` получает список государств.
3. Правило `config.nations` как в эталоне (`default` = все государства карты; компактных карт у нас пока нет).
4. Боты: `bots` = 400 по умолчанию, спавн на суше вне клеток государств, детерминированный сид.
5. Проверка: `perf-sim` с 400 ботами на мировой карте (бюджет: средний тик ≤ 10 мс, максимум ≤ 50 мс), тесты детерминизма, документ калибровки.
