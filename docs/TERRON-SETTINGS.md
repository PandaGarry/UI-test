# Настройки Terron: что у них и что берём

Источник: клон OpenFrontIO (`src/client/UserSettingModal.ts`, `AccountSettingsModal.ts`,
`LazyModals.ts`, `theme/ThemeProvider.ts`). Код не копируем, только состав и логику.

## Где что лежит
- **Главное меню:** язык (RU | EN в футере). Настроек в меню нет.
- **Аккаунт:** отдельное окно `AccountSettingsModal` (появится с системой аккаунтов, см. пункт 2 решений).
- **Игра (HUD):** одно окно `UserSettingModal` с вкладками. Это и есть «настройки».

## Вкладки игрового окна
1. **Геймплей** (`renderGameplaySettings`): предупреждение-рамка, ценник курсора,
   эмодзи-меню и модификатор, имена анонимно, левый клик открывает меню, атака долей
   (шаг и текущее значение), защита от ядерного союза, переход к игроку, оверлей
   производительности, подсказки, оверлей атакующих войск, Steam-ссылки, реплей,
   координатная сетка, прозрачность HUD, пауза, быстрый чат, меню модификатора строек.
2. **Графика:** пресет качества, обновление (модификатор), расширенные слои.
3. **Экран** (только десктоп-оболочка): режим окна, масштаб интерфейса, монитор.
4. **Звук:** громкость по категориям, выключение при сворачивании, оповещения
   при неактивном окне, пробный звук, сброс.
5. **Клавиши:** движение, зум, атака, строительство, союзы, выбор кораблей,
   меню-шорткаты.

## Тема
Тема у Terron — набор цветов для территорий, границ и структур игроков
(`ThemeProvider`, `default-theme.json`). Есть и цветовой вариант для дальтоников.
У нас `theme` задаёт цвета территорий (`GameTheme`). Сейчас в списке одна тема «Пастельная».

## Что берём в наш план
- Окно настроек только в игре; в меню остаётся язык. Совпадает с текущей реализацией.
- Вкладки по образцу Terron: Геймплей, Графика, Звук, Клавиши (+ Экран для десктопа позже).
- Геймплейные настройки добавляем по мере появления механик (Этап 3+).
