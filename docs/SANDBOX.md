# Песочница: быстрый старт (читать первым после очистки)

Если песочница очистилась или не хватает инструментов, выполни по порядку, без лишних отчётов о состоянии:

1. `cd /home/user/UI-test && bash scripts/sandbox-setup.sh`
   - синхронизирует ветку `arena/0330549f-ui-test` с origin (fast-forward, если нет локальных изменений);
   - ставит зависимости клиента (`npm ci` в `client/`);
   - ставит headless Chromium из npm (`@sparticuz/chromium`) и puppeteer-core в `~/.chr`, распаковывает библиотеки и запускает smoke-тест.
   - Повторный запуск безопасен.
2. Игра: `bash scripts/run-prod.sh` (сборка и сервер на порту 8080, запускать как фоновый процесс).
3. Скриншоты: `LD_LIBRARY_PATH=$HOME/.chr/al/lib node $HOME/.chr/shot.mjs $HOME/.chr/shots`
   - снимает меню, лобби, спавн и игру в `~/.chr/shots-*.png`.
   - Лобби открывается: кнопка «Создать лобби» отключена, пока имя игрока не введено. Скрипт `shot.mjs` вводит имя перед кликом. Ошибка была в тесте, не в игре.
   - Снимок после клика по «Начать игру» показывает таймер выбора места старта (10 с).
4. Проверки перед коммитом: `cd client && npm test && npx tsc --noEmit -p . && npx vite build`.
5. Замеры симуляции (без браузера): `cd client && npx tsx scripts/perf-sim.ts --map World --bots 30 --ticks 6000 --seed 1` и `npx tsx scripts/check-borders.ts --map Europe --bots 30 --ticks 1200`.

Известные ограничения песочницы:
- CDN Playwright недоступен, поэтому браузер берётся из npm-пакета (см. выше).
- Нет sudo и системных библиотек: всё, что нужно браузеру, лежит в `~/.chr/al`.
- Карты генерируются при сборке (`npm run gen-maps`), кэш в `client/build/cache` (в git не попадает).

Что записывать в отчёт: только итоговый результат (что сделано, что проверено, что осталось), без описания того, что песочница очистилась.
