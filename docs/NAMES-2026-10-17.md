# Подписи территорий и имена ботов (17.10)

## Разбор скриншотов (IMG_5877, IMG_5878)
- Мелкие подписи «стран»: текст сжимался по ширине квадрата территории (`fontSize = size / length`), поэтому длинные имена («Silver Dominion 2») становились нечитаемыми. Эталон задаёт размер по высоте территории.
- Английские слова в русском интерфейсе: сгенерированные имена ботов («Iron Accord», «Silver Dominion 2») были только английскими. Страны (Литва и т. п.) переводятся через `Intl.DisplayNames`, поэтому проблема была только у сгенерированных имён.
- Ник игрока по умолчанию («UnknownPlayer») тоже английский. Не исправлено, см. ниже.

## Сделано
1. `client/src/app/BotNameGenerator.ts`: сгенерированные имена — полные фразы по 24 штуки на язык (EN и RU). У русских имён согласован род («Железный Союз», «Пепельная Республика»). Суффикс после круга — «2», «3».
2. `client/src/renderer/GameFont.ts`: режим `fitHeight` — высота текста 0.46 высоты территории, ширина не сжимается, текст центрируется.
3. `client/src/renderer/layer/NameRenderer.ts`: подписи в режиме `fitHeight`, максимум 44 px (было 28).
4. Белый контур подписей (`halo`) из прошлого шага сохранён.
