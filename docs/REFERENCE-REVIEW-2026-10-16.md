# Сверка с эталоном (анализ), 2026-10-16

Метод: чтение открытого кода эталона (этап 2 «Анализ» по `docs/PARITY.md`) и наш код по тем же участкам:
ввод (касание, правый клик, долгое нажатие), радиальное меню, атака (фронт, потери, отступление), детерминизм симуляции.
Код эталона не копируется. Ниже записаны поведение, цифры и наш статус. Идентификаторы эталона не приводятся.

Проверки в браузере (headless Chrome, 2026-10-16): касание по суше открывает меню (`scripts/ui-tests/enemy2.mjs`);
правый клик по суше открывает меню (`rightclick.mjs`: правый 1, левый 1); касание не отправляет атаку до исправления 7ffd237.

## 1. Что уже совпадает с эталоном (ничего не делать)
- Касание по суше открывает меню, касание по воде не открывает (эталон: вода + выбранные корабли обрабатываются отдельно).
- Правый клик открывает меню (проверено в браузере).
- Порог перетаскивания 10 px, порог долгого нажатия 800 мс для выбора (у нас долгое нажатие пока не используется).
- Центральная кнопка меню = атака. Доля атаки по умолчанию 20% (у нас `DEFAULT_ATTACK_POWER = 0.2`).
- Повторная атака на ту же цель сливается. Встречная атака гасит войска. Анклавы поглощаются (`convertEnclaves`).
- Генератор случайных чисел инициализируется сидом игры (`Game.ts`), приоритеты у всех клиентов одинаковые.
