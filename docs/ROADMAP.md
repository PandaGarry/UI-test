# Роадмап: от WarFront к игре уровня Terron — и лучше

База: WarFront.io (MIT, ~13 тыс. строк). Цель: паритет с Terron.io по ядру
(~206 тыс. строк у Terron) + преимущества там, где Terron слаб.
Код Terron/OpenFront не копируем (AGPL) — только идеи механик.

## Этап 0 — Фундамент ✅ (сделано)
- [x] Монорепозиторий без git-submodule, запуск на Replit одной кнопкой
- [x] Локальная генерация карт (World, Europe), тесты зелёные
- [ ] Выделить детерминированную симуляцию в пакет `core/` (сейчас логика в
      `client/src/game`, серверный раннер её переиспользует через симлинк)
- [ ] CI: сборка + тесты на каждый пуш

## Этап 1 — Ядро Terron-уровня
Каждая механика — отдельным «исполнителем» поверх существующих транзакций
территорий (`client/src/game/transaction`), баланс — в отдельный конфиг:
- [ ] Население как ресурс + прирост от территории
- [ ] Золото, города, фабрики, порты; торговля и торговые корабли
- [ ] Военные корабли, оборонительные посты
- [ ] Ракетные шахты, ПВО (SAM), атомная и водородная бомбы, MIRV
- [ ] Настройки матча: размер карты, кол-во ботов, сложность

## Этап 2 — Игра как продукт
- [ ] Командный режим (сейчас только FFA), союзы и дипломатия, донаты
- [ ] Мультиплеер: довести `server/` (Bun) + лобби, матчмейкинг, реконнект
- [ ] Свой бэкенд аккаунтов и рейтинга (у Terron он закрыт — делаем свой)
- [ ] Туман войны, столицы

## Этап 3 — «Лучше, чем Terron» (клин)
- [ ] Блиц-режим 8–12 минут (у Terron партия 20–40 минут)
- [ ] Реплеи и спектатор с первого дня
- [ ] Ранкед с серверной валидацией действий (античит, которого нет у Terron)
- [ ] Боты с характерами: агрессор, экономист, предатель, изоляционист

## Этап 4 — Рост
- [ ] Сезоны и лига, косметика (скины территорий, эффекты) — без pay-to-win
- [ ] Редактор карт и мастерская (в `api/` уже есть версионирование карт)
- [ ] Клановые войны, мобильная адаптация управления

## Принципы
- Детерминизм симуляции: один `core` для клиента, сервера и ботов; тесты на
  воспроизводимость по сиду.
- Баланс по данным: bot-vs-bot self-play прогоны перед изменением цифр.
- Никакого кода и ассетов из AGPL-проектов (Terron/OpenFront) — только идеи.
