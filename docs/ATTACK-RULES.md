# Правила атаки (что реально ограничивает игрока), проверено по коду 2026-10-16

## Клиент: когда атака отправляется
- Атака по суше: нужна общая граница (`hasBorderWith`, клетка соседствует с территорией цели). Тап по любой клетке цели при общей границе.
- Морская атака: только если нет границы и есть побережье (`findLaunch`).
- Вода: атака не предлагается и не отправляется (`isWater` → `OWNER_NONE - 1`). Раньше граница с водой считалась «границей с целью» → пакет отбрасывался сервером молча (баг, исправлен).
- Себя и пустоту «за водой» атаковать нельзя (`GameMode.canAttack`).

## Ограничения, которых НЕТ
- Количество одновременных атак: нет лимита. Повторная атака на того же врага складывается в одну атаку (`attackPlayer` → `modifyTroops`).
- Частота тапов: нет (ни клиент, ни сервер). На сервере в коде стоит `TODO: Add rate limiting to all actions`.
- Кулдаун: только у ботов (`CooldownBotConstraints`), у игрока нет.

## Ограничения, которые ЕСТЬ
- Войска: атака тратит долю войск (слайдер). Если войск нет, атака не уйдёт.
- Отмена/ответ: возможны через список атак.
