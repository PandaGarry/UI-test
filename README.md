# Frontline (рабочее название)

Браузерная стратегия захвата территорий в реальном времени. Не клон Terron,
а свой вариант жанра на открытой MIT-базе **WarFront.io**: короткие партии
10–15 минут, эпохи матча, фронт и снабжение, доктрины. Стратегия продукта —
в `docs/VISION.md`, пошаговый план — в `docs/PLAN.md`
(© WarFront.io Team, лицензия MIT — см. `client/LICENSE`, `server/LICENSE`,
`api/LICENSE`). Код Terron/OpenFront здесь **не используется** (у них AGPL):
заимствуются только идеи механик.

## Что уже работает

- Одиночная игра против ботов: спавн на карте, захват территорий, атаки,
  лодки для десанта через воду.
- 2 карты: World (2560×1280) и Europe (1280×1280), генерируются локально
  при сборке из `client/resources/maps/` (раньше клиент скачивал карты
  с ныне недоступного API warfront.io — это исправлено).
- Рендер на WebGL-шейдерах, UI, настройки, локализация.
- Тесты клиента: `npm test` (26 тестов).

Мультиплеер пока не подключён: `server/` (игровой сервер на Bun) и
`api/` (аккаунты, реестр карт; нужен MySQL) лежат в репозитории как база
для следующего этапа — см. `docs/ROADMAP.md`.

## Локальный запуск

```bash
npm run setup   # зависимости клиента (один раз)
npm run dev     # дев-сервер Vite с горячей перезагрузкой: http://localhost:8080
npm run build   # production-сборка в client/out
npm start       # отдать production-сборку (http://localhost:8080)
npm test        # тесты
```

Нужен Node.js ≥ 20.

## Структура

| Путь | Что это |
|---|---|
| `client/` | Игра: симуляция, рендер, UI. Бывшие git-submodule (`src/protocol`, `src/map/codec`) теперь лежат прямо в дереве — собирать ничего отдельно не надо |
| `client/scripts/generate-local-maps.ts` | Генератор карт из PNG+JSON в бинарный MapCodec-формат (хуки prebuild/predev) |
| `server/` | Игровой сервер WarFront (Bun, WebSocket, тик 500 мс). Пока не задействован; клиент для раннера подключён симлинком `server/src/runner/client → client/` |
| `api/` | API WarFront: Discord-OAuth, версии карт (нужен MySQL). Пока не задействован |
| `docs/ROADMAP.md` | детальный пошаговый план — в `docs/PLAN.md` |
| `scripts/serve.js` | Статическая отдача production-сборки (`npm start`) |

## Что было исправлено относительно upstream WarFront

1. Удалены git-submodule — все зависимости в одном репозитории, ничего отдельно собирать не надо.
2. Сборка больше не падает без папки `build/` и без `.git` (`git describe`).
3. Карты генерируются локально, а не скачиваются с warfront.io.
4. Дев-сервер слушает `0.0.0.0:$PORT` и разрешает внешние хосты (удобно для облачных IDE).
5. Игровой сервер по умолчанию — локальный, а не warfront.io.
