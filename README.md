# ЯВЬ (JAV) — мобильная MMO-стратегия

> ⚠️ **Статус материалов:** всё в папке `docs/` — **черновики агента, написанные без согласования**.
> Это не утверждённый план и не решения. Актуальные договорённости ведутся в обсуждении с заказчиком.


Мобильная стратегия в жанре MMO-4X (city builder + мировая карта + Роды/альянсы + сезоны)
в оригинальном сеттинге — **славянское тёмное фэнтези** («Явь против Нави»).

Жанр-ориентиры по механикам (без использования чужого IP): Game of Thrones: Conquest,
Viking Rise, Rise of Castles, Rise of Kingdoms, Evony.

## Планируемый стек (см. ADR-1…8)

- **Сервер:** Node 22 + TypeScript, авторитарная асинхронная симуляция (мировой тик 1 Гц,
  планировщик задач), WebSocket + Protobuf, Drizzle ORM (SQLite в разработке → Postgres в продакшене).
- **Клиент:** React + Vite + Zustand + PixiJS, PWA → Android через Capacitor.
- **Инструменты:** `tools/botfleet` (нагрузочные боты = «Мороки»), `tools/econ-sim`,
  `tools/admin` (дашборд мира).
- **Цель по нагрузке:** 1000+ игроков на один мир, доказанная нагрузочным тестом.

## Лицензия и правовые заметки

Проект использует мотивы славянской мифологии (общественное достояние). Все имена, герои,
события и художественные образы — оригинальные. Чужой интеллектуальной собственности
(в том числе названий и персонажей других игр и вселенных) в проекте нет.
