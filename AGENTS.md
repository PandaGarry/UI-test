# Правила для агента (Arena Agent Mode) в этом репозитории

## Первое действие в каждой сессии

1. Запустить `bash scripts/agent-bootstrap.sh` (полный режим; при необходимости `--quick`, если нужен только быстрый проверочный прогон).
   Скрипт сам:
   - переключает на ветку сессии `arena/f737868e-ui-test` и подтягивает её из origin, если она отстаёт (локальные правки сохраняет в `/tmp/arena-bootstrap-backup`);
   - ставит зависимости клиента (`npm ci` в `client/`), если их нет;
   - ставит Python-инструменты карт (`/home/user/tools/maps-venv`);
   - ставит браузер и системные библиотеки для тестов (`/home/user/tools/browser`, см. `env.sh` там же);
   - скачивает исходники эталона (`/home/user/reference/OpenFrontIO`, только чтение) и входные данные Natural Earth (`/home/user/reference/natural-earth`).
2. Прочитать итог (`=== bootstrap summary ===`). Если есть `FAIL`, сообщить пользователю до продолжения работы. `WARN` при `--quick` допустимы.
3. Только после этого продолжать работу.

## Ограничения

- Работать только в ветке `arena/f737868e-ui-test`. Не создавать и не пушить другие ветки.
- Не делать `git push --force` и `git reset --hard` на ветку с локальными коммитами, которых нет в origin. Скрипт этого не делает.
- Вынесенные решения (ask_user) не принимать за пользователя: выбор цвета, силы эффектов, порядка работ и т.п.
- Код эталона (OpenFrontIO, AGPL) не копировать в проект; ассеты эталона (CC BY-SA) не использовать без решения владельца. Цвета эталона в собственной теме допустимы.
- Реальные данные карт — только Natural Earth (public domain). Фундамент F не зависит от настроек графики.

## Документация

- Любой шаг, который меняет поведение, сопровождается правкой в `docs/` (статус, решения, что проверено и что нет).
- Файлы в `docs/` должны соответствовать коду; устаревшие документы помечать баннером статуса.

## Проверка перед коммитом

- `npm test` в `client/` (сейчас 115 тестов, см. docs/STAGE0-BASELINE-2026-10-18.md).
- `npm run build-prod` в `client/`.
- Для UI-изменений: проверка в браузере (скрипты в `/home/user/tools/browser`).
